## 🕹️ About

Minecraft Dungeons II is an action RPG and dungeon crawler developed by Mojang Studios and Double Eleven, and published by Xbox Game Studios. Set across Minecraft-themed lands and the mysterious Sift dimension, players battle a new evil threatening two worlds. The game is planned for release on September 29, 2026, with solo play and cooperative adventures for up to four players.
